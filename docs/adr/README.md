# Architecture decision records

One file per decision that was hard to reverse and easy to forget the reasons for. An ADR is
written when the choice was between several workable designs and the rejected ones would look
attractive again to somebody reading the code a year later.

Naming: `NNNN-short-title.md`, numbered in the order they were accepted. A record is never
edited once accepted, except to mark it superseded by a later one — the point of it is what
was known and decided at the time.
